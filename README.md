# One Line, One Laugh

A single funny line, under 200 characters — one line, one laugh.

> I bought a self-help book. Page one said: return it.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. Python 3.13 standard library only, no network at run time.
